# Система бронирования переговорных помещений

Десктопное приложение для управления бронированием переговорных комнат.

## Стек

- **Python 3.10+**
- **Tkinter** — графический интерфейс
- **SQLite** — база данных
- **tkcalendar** — календарь для выбора даты

## Возможности

- Авторизация и регистрация пользователей
- Три роли: администратор, менеджер, пользователь
- Создание/редактирование/удаление бронирований
- Проверка пересечений по времени
- Поиск свободных помещений на интервал
- Повторяющиеся встречи (ежедневно/еженедельно/ежемесячно)
- Участники встречи
- Вложения (файлы к брони)
- Фильтры и сортировка в таблицах
- Тёмная и светлая темы
